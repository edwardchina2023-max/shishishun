事事顺酒 · 可视化编辑后台 使用指南

这个后台让你像做 PPT 一样改网站：在左侧结构树里点一个位置，右侧前台预览会自动高亮这个元素，你直接改文字、换图片 / 视频，保存即生效。

① 打开后台

http://127.0.0.1:8080

后台已在本机启动，电脑浏览器打开上面的地址即可。（手机访问需用同一台电脑的网络环境。）

② 三大区域

区域作用
左侧 · 结构树站点 → 13 个区块 → 每个可编辑元素。每项都标了它在前台的位置（如「首屏英雄区 / 主标题第二行」），带文字📝 / 图片🖼 / 视频🎬 图标
中间 · 前台预览网站实时预览（同源）。点左侧元素，这里会自动滚动并红框高亮对应位置
右侧 · 编辑面板选中元素后显示它的内容：文字给输入框；图片可上传新图或选图片库；视频可上传替换

③ 改文字

左侧展开「首屏英雄区」→ 点「主标题第二行（事事顺）」→ 右侧输入框改文字 → 点「保存文字」→ 中间预览自动刷新

④ 换图片 / 视频（前线协作）

点对应图片元素 → 右侧点「⬆ 上传新图」（或「上传新视频」）→ 选本地素材 → 点「保存图片 / 视频」。前线同事拿到素材后，按这个路径直接替换即可。

⑤ 发布上线

改完后，点左侧「🚀 部署上线」→ 填提交说明 → 「提交并推送到 GitHub」。GitHub Pages 会自动重新构建，外网随即更新。

⑥ 其他能力（顶部导航，兼容老用法）

面板用途
✎ 文字区块 / 🖼 图片替换和以前一样的扁平列表编辑
🧭 导航菜单改顶部菜单、加子菜单
🍶 产品文案四大旗舰酒款寓意 / 名称 / 文案 / 规格
📄 文件编辑高级：直接改源码（英文小标题改这里）
🗂 图片库网站所有图片，可复制路径

提示：固定英文小标题（BRAND STORY 等）在结构树显示 🔒，一般不动；要改请走「文件编辑」面板。
